# AI Music Video Studio

Planning workspace for a reusable, human-directed music-video production application derived from [Music Video Arena](https://github.com/hershalb/music-video-arena).

- [Proposed design](docs/superpowers/specs/2026-10-29-ai-music-video-studio-design.md)
- [Implementation plan](docs/superpowers/plans/2026-10-29-ai-music-video-studio.md)
- [Upstream audit and fork provenance](docs/upstream-audit.md)

These documents describe proposed software. The checkout still runs the original Arena application; the `studio` commands do not exist yet. Do not run `npm start` expecting the guarded Studio workflow: it starts the original paid autonomous Arena.

No production code, provider calls, dependencies, or media were added by this planning task. Review the proposed scope and engineering defaults before implementation.
